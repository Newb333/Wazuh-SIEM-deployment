# Security Policy

This repository documents a personal Wazuh SIEM lab. It is not a supported production distribution.

## Safe use

- Use the deployment and troubleshooting guidance only on systems you own or are authorized to administer.
- Do not expose the Wazuh Dashboard or API directly to untrusted networks.
- Use TLS with certificate validation enabled.
- Store credentials and private keys outside source control.
- Rotate any credential that may have been exposed.

## Reporting a repository issue

Do not post live credentials, private network details, personal information, or sensitive logs in public issues. Redact evidence before sharing it.
