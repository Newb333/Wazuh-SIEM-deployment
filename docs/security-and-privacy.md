# Security and Privacy

This is a public repository, so I have kept private lab details out of the files and screenshots.

## Details I have not published

- Internal IP addresses and URLs
- PC names, hostnames, usernames, and MAC addresses
- Passwords, API credentials, tokens, and agent keys
- Private keys and certificate files
- Raw configuration backups and unredacted logs

## Before I add screenshots or logs

I check the full image or output, including the terminal prompt, browser address bar, tabs, file paths, and window titles. I replace private values with placeholders or crop the image so those details are not visible.

I do not commit `.env` files, password backups, private keys, certificates, or raw logs. If a real credential is exposed, it needs to be rotated; deleting it from the latest commit is not enough because it may remain in Git history.

Only use these procedures on systems and networks where you have permission.
